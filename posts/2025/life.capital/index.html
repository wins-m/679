我有哪些人生资产

25.6.5 阅读时间：5 分钟

一、技术资产（Technical Capital） 链接到标题

是可以复用、变现，或构建系统的技能与工具集。

操作电脑 + 阅读英语 链接到标题

现代工人素养，受高等教育普及培养。

文档撰写 链接到标题

双语写作，具备多文体能力。使用 Typora 撰写，Simplenote / 坚果云备份，GPT 辅助润色。善于发散联想，能借助 AI 丰富内容并润色语言。表达充分，文风受最近输入影响较大。

资料查询 链接到标题

能使用搜索引擎与 GPT 组合检索信息，善于调整提示词；掌握论坛提问、论文查找与 Zotero 管理、电子/实体资料的获取与归档。

编程 + 脚本化 链接到标题

Python 熟练，能定位并修复大型项目中的错误；擅长环境配置与部署。可从零写出 Python/Shell 脚本并自动化部署，熟悉 Docker 运维与远程开发，能管理本地 NAS 数据。

具备较强的自学能力，在 GPT 辅助下能在两天内上手 Java、Rust 等新语言并启动项目。

数据分析 / 量化研究 链接到标题

能将任务抽象为数据指标，对图表与结构化展示具备较好感知。熟悉统计检验（时间序列、面板数据），具备识别“反向因果”“样本选择”等问题的基本素养。掌握深度网络训练流程（采样、调硬件、loss 设计、训练策略），但调参经验有限。

轻量级 Web 构建 链接到标题

能用 Hugo + Git Page 快速构建静态网页，用于发布内容与资料。

—— 这些技能构成了我独立获取信息、分析、发布内容的完整工具链，支持我自由表达与实现想法。

二、体验资产（Experiential Capital） 链接到标题

通过实际经历获得的独特认知优势。

受教育 链接到标题

义务教育 + 高等教育，提供基础性科学文化资源；也接触了不同背景的同龄人，对教师群体、校园制度、学生组织有观察经验。曾在多个城市中学习/工作过。

旅行 链接到标题

尝试过多种旅行方式（跟团/自由行/自驾/骑行/国际独行），积累了交通、住宿、行程规划的实用经验，也锻炼了计划、执行与临场应变的能力。

通过旅行，我习得了启动行动的勇气，逐步摆脱了“行前完美主义”，建立了独立解决陌生问题的信心，也在与陌生人交流中提升了应对不确定的能力。

金融业 链接到标题

亲身经历金融教育与从业路径，接触过学术界、公募与私募基金圈层；对从业者状态与行业文化有观察。体会过职场的表演规则，也见证了“话术”与“真实”之间的张力。

—— 较早经历“专业是 A 爱好是 B，而 A 不如别人，B 也不如别人”的冲击，无强弱善恶之成见，坚定自我选择，保持对群体趋同与盲从的警觉。

三、时间资产（Temporal Capital） 链接到标题

自由支配的时间与使用时间的能力。

长期自主 链接到标题

目前年轻、健康、无家庭负担，无不可抗干扰，时间属于自己，能依据身心状态安排日常。

坚持习惯 链接到标题

保持运动/冥想/输入学习的习惯，让生活有节奏；定期反思纠偏，持续优化状态。

计划与进度管理 链接到标题

辞职后建立每周计划表（结合 GPT 生成与追踪），配合《认知觉醒》等书的启发，唤醒了应试时代的节奏感，在完全自主的生活中激发出个人潜能。

—— 我的时间不仅自由，还有较高质量，这是生活习惯、物质基础与时间管理能力协同的成果。

四、网络资产（Network Capital） 链接到标题

我与他人及平台所建立的、可互助共创的信息网络。

技术交流者 链接到标题

包括技术从业的朋友、前同事；投资行业社群；学术圈与出版圈联系人；技术社区与 GitHub 作者。

创作者 / 独立思考者 链接到标题

包括从事文学/艺术创作的朋友、豆瓣友邻、旅行途中遇到的个体，以及通过书籍、期刊接触到的思想者。

线上内容平台 链接到标题

利用去中心化平台获取高质量内容，绕开推荐算法与地域限制。具备有效筛选与判断能力，能连接真实个体，不容易被错的信息误导。

—— 虽不擅长主动社交，但我懂得记录与表达，也知道在需要时，通过线上渠道找到支持与启发。

五、精神资产（Spiritual Capital） 链接到标题

支持我做选择与行动的信念、审美与自我对话能力。

自我反思 链接到标题

借助写作与冥想，定期复盘与净化思绪，保持觉知感；配合香薰与燃香，使精神生活保持纯度。

追问自由/自主/意义 链接到标题

在行动前先判断价值，宁愿行动少，也要自洽。即使无产出，只要理念被认可，也能满足。精神性的认可，是行动的动力。

从输入中获得精神养分 链接到标题

自然、电影、书籍给予我精神滋养。有人可在机械琐事中建构精神王国，我不行。我不能接受“双重思想”的分裂生活。希望建立一个自足、连贯的精神系统，并由此出发与外部连接。

六、我最珍惜的资产？ 链接到标题

四面是水，而无水可用。我最珍惜的是精神资产。

因为：

  • 技术资产：方向明确、100 小时速成；
  • 体验资产：有时间 + 有物质即可获取；
  • 时间资产：靠计划与设施支持可累积；
  • 网络资产：靠参与与记录可稳步增长。

但精神资产：

  • 非线性积累；
  • 需决心 + 状态 + 条件 + 环境同时就位才有质变；
  • 一旦停止觉察与对话，会悄然消失于日常琐碎中。

精神资产是我选择与创作的出发点。当精神富足时，我不会被纷扰所动，能在喧嚣中抓住真正的自我。

自由不是逃离农活的喜悦，而是即便选择农活，也能感到真实的充实。不是躲避困苦，而是赋予困苦以意义。倘若你的精神系统已被外部设定，那么你的“感谢”可能只是被驯化后的合理化。

Where your heart is, there your treasure will be.

精神贫瘠者没有真正的选择自由，也没有真正的感谢自由。
